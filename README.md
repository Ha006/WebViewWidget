# Sökmotorn

Minimal Flutter app that shows [sökmotorn.se](https://sökmotorn.se) (`https://xn--skmotorn-n4a.se`) in a webview.

- Bundle id: `se.klasholmgren.sokmotorn`
- Back button / swipe-back history, home & reload buttons, progress bar
- External links, mailto: and tel: open in Safari / system apps
- App icon generated from the site's apple-touch-icon (`flutter_launcher_icons`)
- iOS builds via Codemagic (`codemagic.yaml`), see [SETUP.md](SETUP.md)
